## Anchor-point pinning of the zoom-to-home transitions (new in 16.2)
`shouldForceDefaultAnchorPointForTransition` (+setter) and six overrides on `SBFullScreenToHomeCenterZoomDown/SlideOver/IconZoomSwitcherModifier` (0x1c7834624.., 0x1c7836d34.., 0x1c75b2d8c..), IconZoom extras (`appLayout`, `shouldDisableAsyncRendering`, `asyncRenderingDisabled`, `dockUpdateMode`=3, `appLayoutsForContinuousExposeIdentifier:`, changed `shouldAsyncRenderUntilDelay:` 0x1c75b2034 and `wantsDockBehaviorAssertion` 0x1c75b3988), SlideOver `scaleForIndex:`/`visibleAppLayouts`, and `SBHomeGestureRootSwitcherModifier` `ensuresSelectedAppLayoutUsesAnchorPointSpacePinning` + two pin queries (0x1c78ee270/338). Every 16.2 creator sets the flag to `isChamoisWindowingUIEnabled` (home gesture: the root flag the CE root sets to YES), so a modifier whose 16.0 creator cannot set it answers with that same query (documented derived default). NOT ported (other owners): PIP / PIPRestore variants (new init with `layoutRole:`), `SBHomeGestureRootSwitcherModifier` transition/gesture child changes (G1C fly-in), `_configureChamoisGestureRecognizersIfNeeded` (creates the strip-reveal `SBGrabberTongue`, gesture manager), per-class creator calls in floor/HomeScreenCE/WindowDrop.

- `-[SBFullScreenFluidSwitcherRootSwitcherModifier transitionModifierForMainTransitionEvent:]` 16.2 0x1c762c998 reimplemented in full (group `G1B_FluidRoot`, helper block `G1B_FR_*`): the chamois flag first, banner unfurl, breadcrumb (SlideOver, force flag), deck / grid, rotation, pulse (4-arg `SBSplitDisplayItemPulseTransitionSwitcherModifier` init with `chamoisWindowingUIEnabled:`), peek -> SlideOver (`isCenterWindowToSlideOverEvent` / `isCenterWindowToNewSplitViewEvent` in the 16.2 order), morph-from-PIP (`SBPIPRestoreToFullScreenSwitcherModifier` with `toLayoutRole:` from `morphingPIPLayoutRole`), window delete / commit / decline, split removal (masks Center 0x10, Primary|Side 6), Crossfade `setFullScreenTransition:(!chamois)`, Dosido, Crossblur, and app -> home (`isEnteringAnyPeekEvent` early exit, PIP / IconZoom / SystemAperture / CenterZoomDown with the force flag = chamois).
